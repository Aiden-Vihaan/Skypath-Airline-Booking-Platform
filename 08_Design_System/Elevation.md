# SkyPath Elevation System

## Purpose

Elevation establishes hierarchy between surfaces without relying on excessive borders.

---

## Elevation Levels

### Level 0 — Flat

Used for:

- Main page backgrounds
- Large content areas
- Static sections

### Level 1 — Subtle

Used for:

- Cards
- Flight result containers
- Form groups

```text
0 1px 2px rgba(15, 23, 42, 0.08)

### Level 2 — Medium

Used for:
Floating controls
Dropdowns
Important interactive cards
0 4px 12px rgba(15, 23, 42, 0.10)

### Level 3 — High

Used for:
Modal dialogs
Important overlays
Sticky booking summaries
0 10px 24px rgba(15, 23, 42, 0.12)
