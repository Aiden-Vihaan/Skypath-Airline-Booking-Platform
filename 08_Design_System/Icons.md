
# SkyPath Icon System

## Purpose

Icons support recognition and scanning throughout the booking experience.

Icons should supplement labels rather than replace essential text.

---

### Navigation

- Back
- Forward
- Menu
- Close
- Home
- Profile

### Booking

- Calendar
- Passenger
- Seat
- Baggage
- Payment

### Information

- Information
- Help
- Warning
- Error
- Success

### Actions

- Edit
- Delete
- Add
- Remove
- Filter
- Sort
- Download
- Share

---

## Icon Principles

- Use one consistent icon family.
- Maintain consistent stroke weight.
- Avoid mixing filled and outlined styles without a clear hierarchy.
- Pair unfamiliar icons with text labels.
- Do not use color alone to communicate meaning.
- Maintain sufficient touch area around interactive icons.

---

## Accessibility

Decorative icons should be hidden from assistive technologies.

Functional icons require accessible labels.

Example:

```text
Icon: Edit
Accessible label: "Edit passenger details"
