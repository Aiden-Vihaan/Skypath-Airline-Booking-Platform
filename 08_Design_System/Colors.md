# SkyPath Color System

## Purpose

The SkyPath color system establishes a consistent visual language across booking, flight comparison, passenger management, seat selection, payment and post-booking experiences.

The system prioritizes:

- Clear visual hierarchy
- Accessibility
- Strong interaction feedback
- Trust during payment and booking
- Consistency across desktop, tablet and mobile

---

## Brand Colors

| Token | Value | Usage |
|---|---|---|
| Primary | #1D4ED8 | Primary actions, selected states, links |
| Primary Hover | #1E40AF | Hover state |
| Primary Pressed | #1E3A8A | Pressed state |
| Secondary | #0F766E | Supporting actions and secondary emphasis |

The primary blue communicates reliability, navigation and action without competing with critical status colors.

## Feedback Colors

### Success

**#15803D**

Used for:

- Successful payment
- Confirmed booking
- Available flight states
- Completed steps

### Warning

**#B45309**

Used for:

- Fare limitations
- Expiring sessions
- Important booking warnings

### Error

**#B91C1C**

Used for:

- Invalid form fields
- Payment failures
- Booking errors
- Unavailable actions

### Information

**#0369A1**

Used for:

- Informational messages
- Fare explanations
- Policy guidance

---

## Flight States

SkyPath uses explicit visual states for flight availability:

- Available — Green
- Selected — Primary Blue
- Unavailable — Neutral Gray
- Recommended — Purple

Color is never the only indicator of state. Labels, icons or supporting text accompany important states.

---

## Accessibility

Text and interactive elements must maintain sufficient contrast against their backgrounds.

Critical information such as errors, warnings and booking status must never depend on color alone.
