# SkyPath Spacing System

## Purpose

The spacing system creates predictable relationships between content, components and sections.

SkyPath uses a 4px base spacing unit.

---

## Spacing Scale

| Token | Value | Typical Usage |
|---|---:|---|
| 1 | 4px | Icon/text relationships |
| 2 | 8px | Tight component spacing |
| 3 | 12px | Form fields and labels |
| 4 | 16px | Standard component padding |
| 5 | 20px | Card content |
| 6 | 24px | Section spacing |
| 8 | 32px | Major content groups |
| 10 | 40px | Page sections |
| 12 | 48px | Large layout separation |
| 16 | 64px | Major page transitions |

---

## Layout Principles

### Consistency

Equivalent components should use equivalent spacing.

### Grouping

Related information should be closer together than unrelated information.

### Breathing Room

High-risk interactions such as payment and passenger information should have sufficient spacing to reduce mistakes.

### Responsive Behavior

Spacing may reduce on smaller screens while maintaining the same visual hierarchy.

---

## Touch Targets

Interactive controls should provide a minimum touch target of approximately 44 × 44px.

This is particularly important for:

- Seat selection
- Checkboxes
- Date selectors
- Navigation controls
- Add-on controls
