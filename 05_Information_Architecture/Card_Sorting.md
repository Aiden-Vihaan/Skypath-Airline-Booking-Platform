# Card Sorting

## SkyPath — Information Architecture Study

Card sorting was used to explore how users naturally group and label the information involved in an airline booking journey.

The activity helped establish a navigation structure that follows the traveller's mental model rather than simply reflecting the internal structure of the product.

---

## Objective

The objective was to determine:

- Which information users consider related
- Which categories feel intuitive
- Which labels are easy to understand
- Which features should remain together
- Which information should be accessible from the primary navigation
- Where potential navigation ambiguity exists

The findings were used as an input to the SkyPath information architecture and sitemap.
