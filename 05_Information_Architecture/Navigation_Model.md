# Navigation Model

## SkyPath — Airline Booking Platform

The SkyPath navigation model is designed around the traveller's tasks rather than the internal structure of the product.

The navigation separates the primary booking journey from post-booking management while keeping support accessible throughout the experience.

---

## 1. Navigation Objectives

The navigation model aims to:

- Make the primary booking task easy to start
- Keep flight search and comparison closely connected
- Reduce unnecessary navigation during booking
- Make the user's current stage understandable
- Provide clear access to existing bookings
- Keep check-in easy to find
- Provide support without interrupting the main journey
- Maintain predictable navigation across desktop and mobile layouts
