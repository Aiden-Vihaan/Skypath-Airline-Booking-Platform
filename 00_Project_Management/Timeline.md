# SkyPath — Project Timeline

## 01. Project Definition

### Objective
Define the product concept, problem space, target users, scope and intended outcome.

### Key Outputs
- Project brief
- Problem definition
- Project objectives
- Initial scope

---

## 02. Product Strategy

### Objective
Establish the product vision, value proposition, strategic goals and experience principles.

### Key Outputs
- Product vision
- Product objectives
- Experience principles
- Strategic considerations

---

## 03. Competitive Research

### Objective
Understand existing airline and travel-booking experiences and identify recurring interaction patterns, strengths and usability opportunities.

### Key Outputs
- Competitive landscape
- Competitor comparison
- Interaction observations
- Opportunity areas

---

## 04. User Research

### Objective
Develop a research-informed understanding of traveller behaviours, expectations, motivations and pain points.

### Key Outputs
- Research insights
- Behavioural patterns
- User needs
- Opportunity statements

---

## 05. Personas

### Objective
Translate research-informed patterns into representative user models.

### Key Outputs
- Student traveller persona
- Frequent professional traveller persona
- Family/leisure traveller persona
- Empathy maps
- Design hypotheses

---

## 06. Information Architecture

### Objective
Define the structural organisation of the platform and establish relationships between major areas of the product.

### Key Outputs
- Sitemap
- Content hierarchy
- Navigation structure
- Booking architecture

---

## 07. User Flows

### Objective
Model the primary and alternative interaction pathways required to complete the booking journey.

### Key Outputs
- Flight-search flow
- Flight-selection flow
- Passenger-information flow
- Seat-selection flow
- Payment flow
- Confirmation flow
- Recovery paths

---

## 08. Low-Fidelity Wireframes

### Objective
Translate the information architecture and user flows into preliminary interface structures.

### Key Outputs
- Search wireframes
- Results wireframes
- Flight-details wireframes
- Passenger-information wireframes
- Seat-selection wireframes
- Review and payment wireframes
- Confirmation wireframes

---

## 09. Design System

### Objective
Establish the visual and interaction foundations required for a consistent interface.

### Key Outputs
- Colour system
- Typography
- Spacing
- Grid
- Components
- Interaction states
- Accessibility considerations

---

## 10. Component Library

### Objective
Create reusable interface components and variants.

### Key Outputs
- Buttons
- Inputs
- Cards
- Navigation
- Flight components
- Selection controls
- Feedback states
- Booking components

---

## 11. High-Fidelity UI

### Objective
Translate the validated structural direction into a coherent visual interface.

### Key Outputs
- High-fidelity screens
- Responsive layouts
- Visual hierarchy
- Interaction states

---

## 12. Interactive Prototype

### Objective
Connect the principal screens into a representative end-to-end booking experience.

### Key Outputs
- Search interaction
- Flight selection
- Fare selection
- Passenger details
- Seat selection
- Payment
- Confirmation
- Post-booking access

---

## 13. Usability Evaluation

### Objective
Evaluate the interaction model and identify usability opportunities requiring further refinement.

### Key Outputs
- Evaluation scenarios
- Findings
- Severity classification
- Improvement opportunities
- Iteration recommendations

---

## 14. Iteration

### Objective
Refine the interface based on identified usability and design opportunities.

### Key Outputs
- Revised components
- Revised layouts
- Interaction improvements
- Accessibility refinements

---

## 15. Case Study Documentation

### Objective
Document the complete design process, decisions, rationale, limitations and future opportunities.

### Key Outputs
- UX case study
- Design rationale
- Reflection
- Limitations
- Future roadmap

---

## 16. Portfolio Preparation

### Objective
Translate the complete project into a concise portfolio presentation while retaining the strongest evidence of the design process.

### Key Outputs
- Portfolio case study
- Project overview
- Selected process artefacts
- Final interface presentation
- Prototype reference
